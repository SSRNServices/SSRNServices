## About

I build backend systems, automation pipelines, and AI-driven tools designed to run in production — not sit in a demo repo.

My work centers on architecture that scales predictably, automation that removes manual work entirely rather than just speeding it up, and AI applied where it earns its place, with real production constraints in mind. I also spend a disproportionate amount of time on the problems most people avoid: state management, sync consistency, and concurrency under load.

```text
const philosophy = {
  build:    "systems, not features",
  optimize: "for reliability under scale",
  handle:   "edge cases before they become incidents",
};
```
