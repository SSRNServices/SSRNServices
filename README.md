## About Me

Most developers ship features. I build the systems those features run on — architectures that scale, stay reliable under real users, and don't quietly rot in production.

My focus is backend engineering, automation pipelines that remove manual work entirely, and applying AI where it actually earns its place in a product — not as a demo layer bolted on top.

- 🔭 Currently scaling backend systems for real-world usage
- 🛠️ Building automation-first products that eliminate manual ops
- 🤖 Applying AI in practical, production-usable systems
- 🐛 I like the debugging problems most people avoid — state, sync, and concurrency issues
